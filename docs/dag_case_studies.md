# 固定与动态 DAG 的逐题优势案例

这两例从已冻结的留出实验轨迹中事后选出，用于定位可能的机制，不用于估计平均收益。运行 `python benchmarks/case_studies.py` 可从本地 Git 忽略的结果文件复核数字；脚本不输出题目、标准答案或模型预测。

## 固定 DAG：BrowseComp-Plus 候选池题，offset 172

同一题、同一 `deepseek-flash` 模型、同一候选文档池和逐题 32,000 observed-token 上限。单节点严格答案匹配为 0，用 12,193 token；固定双线索 DAG 为 1，用 27,142 token；自由动态 DAG 在 35,301 token 后超预算，未给出答案。单节点与固定 DAG 都读到全部 gold 文档，因而这例的差异发生在**已检索证据的使用和答案形成**，不能归因于固定 DAG 找到了新文档。

这是一道固定 DAG **答案质量优于此前单节点与动态基线**的真实模型样例，但它多用了约 2.23 倍 token。不能据此断言固定 DAG 在同等实际消耗下更好；全批六题里，固定和单节点同为 4/6。

## 多级动态 DAG：MuSiQue 分叉题，ID `4hop3__275416_24325_156850_10557`

同一题、20 段材料、同一模型与 24,000 observed-token 上限。单次单节点、单节点复查、固定双线索 DAG 的答案与支持证据联合精确匹配均为 0；允许一级子节点生成孙节点的动态 DAG 实际扩展 1 次，联合精确匹配为 1。四者 token 分别为 2,562、5,192、7,501、17,910；最终支持证据召回分别为 0.50、0.50、0.75、1.00。

这是一道多级动态 DAG **同时优于单节点、复查和固定 DAG 的联合正确性样例**，代价是固定 DAG 约 2.39 倍、单节点约 6.99 倍 token。整批分叉题中，动态 DAG 联合正确 2/6，固定 DAG 0/6，单节点 1/6；链式题中四种策略均为 0/6。已有轨迹审计显示，分叉题的孙节点没有读到固定 DAG 未读到的标准支持段落，因此这例更符合“证据整合改善”的候选解释，不能声称扩图发现了新必要证据。

## 下一步验证

两例均为**事后发现的个例**。应预先定义结构条件，再在全新题目上检查同类案例是否重复出现：固定 DAG 侧重点是多个独立证据线索的整合；动态 DAG 侧重点是执行中出现的必要缺口，并记录孙节点是否取回基线缺失的标准证据。每题仍需报告实际 token、调用次数、错误和同预算单节点复查，避免把额外采样的效果直接归给 DAG 形态。
